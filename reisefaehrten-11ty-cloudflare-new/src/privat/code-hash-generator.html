Code-Hash-Generator

Internes Werkzeug für die Einrichtung neuer privater Alben. Gewünschten Zugriffscode eingeben und den erzeugten Hash in die Zeile expectedHash der jeweiligen Album-Seite einsetzen.

Hash zum Einsetzen:

Diese Seite läuft komplett im Browser — der eingegebene Code wird nirgends verschickt oder gespeichert. Sie ist selbst nicht öffentlich gelistet, muss also nicht extra entfernt werden, kann aber bei Bedarf einfach gelöscht werden.
